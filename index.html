Pedro Lara GDE

Fine-Tuning Gemma for Fact Retrieval: A MeMo-Based Approach to Next-Gen RAG Systems

Ver descripción del taller

This presentation explores a practical, end-to-end implementation of the Memory Model (MeMo) architecture, offering a compelling approach for developers building advanced agentic pipelines or enhancing Large Language Model (LLM) memory beyond traditional Retrieval-Augmented Generation (RAG). Attendees will be guided through a comprehensive Colab notebook demonstrating a dual-model framework that separates reasoning from factual recall. The session covers the complete technical pipeline—from automated fact extraction, semantic consolidation, and cross-document synthesis for multi-hop reasoning—to the final execution of a multi-turn inference loop orchestrating Gemini as the Executive model for question decomposition and synthesis, alongside a LoRA-fine-tuned Gemma via KerasHub acting as the parameterized Memory Model.
